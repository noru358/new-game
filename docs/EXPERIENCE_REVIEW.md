# v22 플레이 피드백과 다음 샘플 후보

2026-09-30. 실행 기준 3f304bd2. 아래 후보는 사용자 선택 전이며 마스터 설계 변경이나 구현 완료를 뜻하지 않는다.

## 확인한 사실

- HUD: hybrid_height.gd의 기본 상태/HP/카드 요약/조작·적 색상 안내, run_growth.gd의 레벨/누적 해금, hybrid_region.gd의 런 시간·적 수, section의 지역 안내가 별도 Label로 누적된다. v22 960×540 렌더에서도 왼쪽 세로 영역 대부분을 텍스트가 차지한다.
- 각성: 야영지 장비 버튼에 획득한 각성 설명을 덧붙인다. 별도 획득 기록/현재 적용 상태 화면이 없다. 일시정지는 이번 런 카드만 보여준다.
- 정원 각성은 A_EMBER 장착 시 마탄 피해 +20%p와 연쇄 +1. 계곡 각성은 주공격 W_ECHO 장착 및 4타 적중 시 0.25초 후 추가 폭발. 장비를 착용하지 않아도 각성 획득은 저장된다. 이번 사용자가 실제로 어느 장비를 썼는지는 모른다.
- 두 히든은 공간·적 배치가 다르지만 모두 정해진 적을 전부 처치한 뒤 제단에서 고정 보상을 받는다. 계곡은 두 전투의 순서까지 고정되어 있다.
- 정글 본선은 상층 석계단/하층 협곡의 물리적 경로 차이가 있다. 경로 자체가 없다는 진단은 틀리다. 그 차이가 발견 욕구·목적지 선택으로 충분히 전달되는지는 별도 문제다.
- 사원 보스는 돌진/충격파/후반 고리, 정글은 횡쓸기/강풍/후반 연속 공격이다. 패턴 뒤 1.2~1.45초 반격 정지가 있으며 일반 공격은 항상 피해를 준다. 코드 검사만으로 최신 플레이가 쉬웠던 이유를 단정하지 않는다.

## 원인 가설

- 폭포 입구만 특별한 색과 모양으로 떨어져 있으면 숨은 틈보다 상호작용 표식처럼 보일 수 있다. 주변 암벽·다른 물줄기·식생과 하나의 장소로 묶고 통행 가능한 틈에 단서를 남기는 샘플을 제안한다.
- 탐험은 길이 갈라지는 것 외에도 보이는 목적지, 돌아갈 이유, 좁고 넓은 공간의 대비, 발견 뒤 기존 동선을 새롭게 이해하는 경험이 필요할 수 있다. 면적·장식 증가만으로 해결된다고 가정하지 않는다.
- 각성 효과가 안 보이는 문제는 미장착/발동 조건/설명/효과 표현/성능 크기를 구분해 확인해야 한다. 먼저 보상 수치부터 올리지 않는다.
- 보스는 위험도와 선택이 부족한지, 같은 회피만 반복하는지, 반격과 타격 반응이 부족한지를 최신 플레이 질문으로 나눈다.

## 첫 시험 후보 — 미승인

1. 전투 HUD: 생존·사용 가능 행동·짧은 현재 목표를 우선 배치. 카드 요약은 유지하고 설명은 일시정지로 통합. 누적 해금/적 수/조작 범례는 별도 상세로 이동하는 안을 제시한다.
2. 각성 UI: 획득 순간 전후 효과와 현재 적용 여부 표시, 야영지의 영구 발견 기록, 일시정지의 현재 장비·각성 상태. 미발견 장소/보상의 사전 노출 범위는 사용자에게 묻는다.
3. 본선 한 구간: 멀리 보이는 목적지→가려진 접근로→짧은 우회/발견→익숙한 경로 재연결을 실제 배치로 비교. 모든 맵에 같은 순환 구조를 복제하지 않는다.
4. 히든: 정원은 고요한 장소 탐색과 흩어진 수호 적, 계곡은 물길·폐유적의 접근 경로 발견을 중심으로 차별화하는 후보. 장치·퍼즐·웨이브 추가를 모든 히든에 강제하지 않는다.
5. 보스: 플레이 정보 후 지역별 위치 판단/회피 방향 변화/반격 보상을 작은 단위로 시험. 기존 자유 출입·HP 유지·1회 재도전·콤보 반격 기회는 이미 합의된 조건이다.

## 이번 작업 검사

DEV_STATUS/MASTER/AGENTS, HUD·야영지·각성 적용·두 보스 코드와 정글/히든 지형, 기존 v22 렌더를 대조했다. 이번 변경은 조사 기록과 상태 문서만이며 게임 실행·새 자동 검사·새 배포 빌드는 없다. 이전 v22의 45개 통과는 이 조사에서 다시 실행한 결과가 아니다.

## 후속 승인과 구현

사용자는 UI 전반 정리, 각성 3종 표시, 물길/갈림·합류/복귀 길 혼합, 2~3분 목표, 계곡 자연 탐험과 도착 보상, 두 보스 반격 추가 피해, HP1800/2000 시험, 장비 상세 및 성장 탭 분리를 선택했다. v23에서 해당 범위를 구현했다. 당시 미승인 후보 전체가 자동 승인된 것은 아니다. 본선 전면 재구성·퍼즐·새 무력화 게이지·최종 아트는 구현하지 않았다. 현재 검증과 다음 작업은 DEV_STATUS를 따른다.

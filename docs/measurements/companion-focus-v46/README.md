# 동행 분기 집중 대상 시험

목적은 새로운 수치 축보다 직접 공격으로 동행의 우선 대상을 정하고 위치를 바꾸는 행동 차이다. 기존 COMPANION 분기는 여우불 피해+10%이며 자동 사격은 가까운 유효 적을 고른다. 기존 평타/이동 베기 연계 카드는 발사 대기를 줄이지만 대상을 지정하지 않는다.

후보는 기본 false인 companion_focus_trial이며 COMPANION일 때만 설치된다. 기존 상점 설명/기본 게임은 아직 바꾸지 않았다. 주 평타의 실제 체력 감소 및 생존을 확인하는 basic_target_struck 신호만 사용한다. 기존 attack_landed/피해/공격 시각은 그대로다. RIPPLE·이동 베기·동행·연쇄·봉인 타격은 지정하지 않는다.

동일 공격의 실제 생존 명중 대상을 접촉 당시 전방 정렬→거리→위치/역할 순으로 결정하고2초의 활성 시간 동안 우선한다. 기존 발사체는 방향을 바꾸거나 추가 발사하지 않는다. 지정 대상이 화면/거리/벽/이미 날아가는 피해 예약 조건을 통과하지 못하면 원래 선정을 쓴다. 사망/숨은 장소 전환/보스 경계 이탈/재도전/런 종료는 지정과 표시를 지운다. 새로 늘어난 동행도 같은 임시 지정을 읽는다. 저장/가격/피해/발사 간격은 변경하지 않는다.

로컬 Godot4.6.3 계약34검사 PASS: 실제 주 타격→지정, 더 가까운 비지정 적보다 우선, 실제 발사체의 명중, 같은 공격 순서 반전/집결 이동, 새 동행, 일시정지/만료, 실제 물리 벽, 화면/거리/예약 피해, 비활성 그룹/재도전, RIPPLE/치명타/보스 거부, 무분기/DIRECT 기본 피해 보존. 합성 fixture이며 자연 플레이/재미 검증은 아니다. 처음 test의 타입추론 오류는 명시적 String으로 고쳐 재실행했고 실패 표본은 통과로 세지 않는다.

발사체는 여전히 앞의 적이나 벽에 막힌다. 후방 적을 무조건 관통하거나 명중시키는 효과가 아니다. 의도는 먼저 주요 적을 때리고 사선이 통하는 위치로 움직이는 선택이다. 원격 전체 회귀와 두 해상도 실제 마커 렌더 및 정상속도 교전 비교를 확인한 뒤 채택을 판단한다.

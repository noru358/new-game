# 후보 맵과 야영지의 공통 성장 연결

v44 제출판은 각 후보의 별도 저장을 사용했으므로 후보 보상을 일반 야영지 장비/성장 구매로 연결하지 못했다. 다음 제작 후보는 패키지 미리보기 엔트리에서만 공통 세션을 켜고 야영지·사원후보·정글후보의 profile/unlock prefix를 공유한다. 원본 프로젝트의 일반 실행은 기존 씬/저장을 유지한다.

- 신규 공통 기록은 사원 미클리어·정글 잠김으로 시작한다. 기존 정글 단독 시험의 합성 첫클리어/6레벨 해금은 이 모드에서 주입하지 않는다.
- 사원 성공→야영지 정산액→장비 구매→별도 장착→영구 HP 구매→정글 출정에 같은 기록이 사용된다. 별도 신규 미리보기 prefix이며 v43 일반 저장이나 v44 개별 시험 기록을 파괴/이행하지 않는다.
- 공통 미리보기의 첫 출정 두 버튼이 실제 후보 맵을 연다. 발견탭의 사원/정글 개발 진입 두 버튼은 이 모드에서 제외하여 정글 잠금 우회를 만들지 않는다. 다른 개발 장소/습지는 아직 별도 구간이다.
- 로컬 Godot4.6.3: 공통 기록59검사, 기존hub layout 및 정글후보 회귀 통과. 검사에서 사원 성공과 수입100을 주입했으므로 저장/구매/장착/적용의 상태 계약 검사이지 자연 전투 승리·경제 적절성·유저 여정 수용이 아니다.
- 공개 제출 앱은 아직 v44/7ea95c6이다. 이 후속 기능의 전체 CI/패키지/실제 입력 여정 확인 후 통합하며 현재 전달판에 적용했다고 보고하지 않는다.

# 습지 석면 수호자 — 독립 전투 후보

## 기획 판단
동남아 → 깊은 사원 습지 → 안쪽 성소의 교전이다. 얼굴 유적과 뿌리의 장소성을 사용한다. 기존 사원/정글의 돌진·근접 충격파 보스와 달리, 플레이어가 서 있던 땅에 순차적으로 뿌리 예고를 남기고 이동 후 가까이 돌아와 반격하게 한다.

- 1단계3회/2단계5회,0.65초 간격으로 서로 독립된 고정 위치의 경고를 놓는다.
- 각 경고는 기존 장판의92반경/0.55초 예고를 사용한다. 보스 피해18, 활성1.35초. 예고 중에는 피해가 없고 생긴 표식은 플레이어를 따라다니지 않는다.
- 마지막 예고 뒤1.35초 반격 창. 기존 직접 타격1.3배 반격, 일반 타격으로 예고 취소 불가, 경계 이탈시 미완료 시전 횟수 보존을 유지한다.
- HP1800은 비교용 기존값이며 난도 수용값이 아니다. 기존 두 보스는 변경하지 않는다.

## 후보 실행 범위
`wetland_boss_trial.tscn`은 안쪽 성소 직전에서 시작하는 독립 조작 시험이다. 주변 일반적은 제외한다. 공간/새 보스 패턴을 먼저 읽고 정상 출정에 통합할 대상으로, 저장/XP/보상/정식 해금은 없다. 240초 성장 런 또는 캠페인 완성을 구현했다고 주장하지 않는다.

성소의 교전 바닥을850×1150으로 확보하고 같은 물/충돌 기록을 함께 수정했다. 전경 돌을 없앨 때 시각과 충돌을 같이 제외한다. 석면의 외형은 저해상도 대표 메시이며 최종 아트가 아니다.

## 검증
- 로컬 Godot4.6.3 상태검사16 + 실제 씬20 통과: 예고/회피/피해, 타격 면역, 경계, 반격,2단계, 종료시 장판 정리, 보행 연결.
- 피해와 보스 격파를 주입한 검사는 상태 계약 확인이며 인간 컨트롤/자연 클리어 증거가 아니다.
- 원격에서는 공식4.6의 전체 검사와 실제 렌더 두 해상도12초 입력을 실행한다.1280 표본의2단계는 별도 명시적 피해 주입으로 시작한다. 실제 결과와 미감/난도 수용은 검사 후 기록한다.

## 첫 실제 입력 관찰과 한 차례 패턴 보완
- cab1ad0의 두 해상도12초 일반속도 원형 이동 표본은 각각11/14회 실제 뿌리 활성화를 보였지만 HP100을 유지했다. 이 표본만으로 재미/난도를 판정하지 않으며, 단순 추종 표식만으로 방향 전환을 요구하지 못하는 위험을 확인했다.
- 마지막 시전(2단계에서는3·5번째)은 현재 속도 방향의0.65초 앞을 최대182거리로 예고한다. 예고가 뜬 뒤에는 위치가 고정되며 방향을 바꾸거나 대시할 수 있다. 피해/예고 길이/보스HP는 그대로다. 활성 시 작은 뿌리 메시를 보여 경고와 실제 위험 상태를 구분한다.
- 이 보완은 다음 실제 렌더/입력 및 자동 검사를 거친다. 무한 수치 조정 대신 여기서 독립 보스 후보의 통합 준비 여부를 판정한다.

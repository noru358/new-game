# 深部 습지 전체 동선 후보 — 2026-10-03 KST

기준은 v44 비교판의 대표 습지다. 비교판과 별도 후보 씬 `deep_wetland_field.tscn`을 사용한다. 이번 공간 확장은 사용자가 승인한 동남아 세 번째 맵의 전체 제작 단계이며, 정식 해금이나 캠페인 완료가 아니다.

## 대지역 → 맵 → 장소 → 행동
- 동남아 / 깊은 사원 습지
- 기존 뿌리 입구 → 참배길 → 얼굴 유적 수변 → 사원뜰을 보존한다.
- 사원뜰 동쪽의 무너진 참배길에서 안쪽 성소로 진입하고, 중앙 물웅덩이 남쪽의 공양터로 돌아 사원뜰에 합류한다.
- 북측 길은 석재 문턱과 원거리 예고, 넓은 성소는 장판·지원 우선순위, 남측 공양터는 뿌리 가장자리에서 돌진 회피 방향을 고르게 한다. 기존 역할만 사용한 잠정 배치다.
- 지형은 물과 마른 땅 경계를 같은 데이터로 만들고, 실제 통행하는 두 경로를 둔다. 수영/점프/복층 또는 강제 전멸문을 요구하지 않는다.

## 구현/검증
- 전체 경계 4000×3000→5600×3000. 실제 새 장소는 동쪽 내부 순환이며 빈 사각 바닥을 늘린 것만으로 볼륨을 판정하지 않는다.
- 5개 추가 기존 역할 배치, 총13명. 장소에 접근해야 최초 활성화하고 물러나도 다시 재우지 않는다.
- 지형·연결·경로·스폰: 로컬 Godot4.6.3 3190 검사 통과.
- 기존 대표 씬247검사 및 뿌리 환경 검사 통과.
- 22개 경유점 실제 이동 입력 통과. 6배 가속/적 비활성/경로 시작 텔레포트 fixture이며 자연 한 판, 정상 체류시간, 난도 증거가 아니다.
- 실제 렌더 검토와 정상속도 교전은 다음 검사. 저장·XP·보상·새 보스는 아직 없으며 기본 UI/배포 앱에 연결하지 않았다.

1. 두 경로와 안쪽 성소를 실제 카메라에서 보고, 불투명 전경/수면·그림자/통행 경계가 맞는지 수정한다.

게임 runtime205파일은 시작과 종료 모두 배포2eae097과 바이트 일치. 빈 격리 XDG 기록0원에서 시작했다. preview session에 격리된 일반 이름의 저장 prefix를 주어 실제 캠프의 사원 후보 출정 경로를 사용했다. tests/sample_first_region_journey.gd는 기존 실제 입력 경제 fixture를 활용하되 사원 후보의 네 지점(중심뜰/회랑/성소접근/보스)으로70초마다 목표를 바꾼다. 고정 card priority, 각 선택1.5초의 합성 대기, time_scale1. 일반 사용자 기록은 접근하지 않았다.

실제 결과는 사망/300초 확인 귀환/사망, 정산236/130/252다. 첫 판 후 HP1(20) 및 A_EMBER(24) 구매와 별도 장착, 두 번째 판 후 POWER1(20)을 실제 UI 입력으로 수행했다. 최종554원, HP110/동행 피해+15%/평타+5%가 후속 출정에 적용됐다. 세 판 모두 출정·결과→캠프·디스크 재조회 상태 일치. 첫/셋째 판27/28선택, 선택 대기 약42/43.6초. 실제 보스 승리는 없고 정글도 열리지 않았다.

해석: 패배한 상태에서도 정산→구매→장착→재출정 연결은 작동한다. 고정 저소비 봇의 잔액을 실제 이용자의 과잉 수입/가격 확정 근거로 쓰지 않는다. 이번 구매는 생존/피해 수치 개선이며 이동·집결·동행 빌드의 행동 차이를 증명하지 않는다. 사람 재미/초보자 성공률/세맵 자연 완주는 미검증이다.

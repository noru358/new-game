# 깊은 사원 습지: 장소별 적 편성

제작 판단: 권역의 다섯 기존 적 역할을 장소에 맞게 섞는다. 잠긴 참배길은 근접/직선 접근, 바깥 뿌리길은 돌아가며 원거리 적 접근, 열린 얼굴수변은 장판 밖으로 재배치, 안쪽 참배길은 돌진 방향 회피, 공양터는 후방 지원 적 우선순위가 목표다. 각 표의40%를 장소,60%를 기존 시간별 압박/회복 편성으로 정한다. 기존 첫45초 근접 적 도입, 적 상한/스폰율/예고/AI/체력/개별 보상/240초 보스/저장 규칙은 유지한다. 역할 비율에 따라 실제 XP와 수입이 달라질 수 있다.

동일 소스와 seed250/grown249투자/270초 bound/같은70초 목표·카드 우선순위·합성1.5초 선택 대기로 기본/후보를 격리된 두 복사본에서 정상속도로 비교했다. 소스·복사본 해시 guard 통과. 선행 두 맵 클리어/성장은 합성 준비값이며 런 안의 승리/피해/체력/XP/시간은 주입하지 않았다.

기본: 실제 성공255.97초,334킬,459획득,27선택,HP2. 후보: 실제 성공258.63초,337킬,495획득,28선택,HP20. 관찰한 일반 적의 장판 활성21→46, 원거리 발사19→27, 돌진 실행28→27. 지원 적은 지속 버프이므로 attacks_fired=0을 무기능으로 해석하지 않는다. 열린 얼굴수변에서 처음 관찰된 장판 적11→24, 그 개체들의 후속 활성11→21. 최초 관찰 시 플레이어 위치로 분류하며 정확한 스폰 순간 위치나 모든 공격 위치를 뜻하지 않는다.

판단: 장소에 맞춘 실제 공격 변화와 끝까지 연결되는 런을 확인해 다음 습지 후보 기본값으로 채택한다. place_encounter_trial=false로 기존 비율 비교를 남긴다. 단일 봇/seed로 난도가 더 좋다거나 경제가 최종 적절하다고 판정하지 않는다. 수입+36/선택+1도 미검증 체감과 함께 추적한다. 실제 렌더/전체CI는 최종 기본값 커밋에서 확인해야 한다. 다른 두 맵은 이 표를 사용하지 않는다.

첫 실행은 관찰 fixture의 혼합 들여쓰기 parse error로 시작하지 못했다. 수정 후 새 격리 복사본2에서 두 실험 모두 정상 종료했다. 실패 표본을 플레이 결과로 세지 않는다.

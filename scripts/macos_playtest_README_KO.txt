루프 정복 — 통합 플레이테스트 v38 / macOS

실행
ZIP을 푼 뒤 LoopConquest-v38.app을 더블클릭하세요.
Godot나 Python 설치는 필요 없습니다. Apple Silicon과 Intel Mac용 실행 파일이 함께 들어 있습니다.
야영지에서 WASD로 ‘출정’에 다가가 E를 누르고 사원으로 출발하세요.

이 앱은 테스트용 자체 서명(ad-hoc)이며 Apple 공증은 받지 않았습니다.
‘개발자를 확인할 수 없음’ 알림이 뜨면, 이 파일을 직접 요청해 받았고 출처를 신뢰하는 경우에만
한 번 실행을 시도한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 이 앱의 ‘확인 없이 열기’를 선택하세요.
‘컴퓨터를 손상시킴’ 또는 ‘손상된 앱’ 경고는 그대로 우회하지 말고 경고 문구를 알려주세요.
Apple 안내: https://support.apple.com/ko-kr/102445

조작
WASD 이동 / J 또는 왼쪽 클릭 공격(누르고 있기 가능) / Shift 대시
Space 이동 베기(첫 누적 레벨업에서 개방) / 1·2·3 카드 선택
E 상호작용 / Tab 지도 / G 귀환 확인 / Esc 닫기·일시정지
장비 구매와 장착은 별도입니다. 귀환 확인은 Tab·Enter·Esc도 지원합니다.

저장과 가격
일반 실행은 기존 저장을 이어 쓰고 기본 영구 성장 가격 20/35를 유지합니다.
저장 위치: ~/Library/Application Support/Godot/app_userdata/Loop Conquest - 1G Complete Run v03
새 가격 70/105의 비교 실험은 이 앱의 기본 진행에 적용되지 않습니다.
현재 저장 형식 v6은 구형 v1~v5 기록을 읽지만, 예전 실행 파일은 v6 저장을 읽지 못할 수 있습니다.

확인할 것 (5개)
1. 우선 일반 사원 한 판: 이동·직접 공격·대시·카드 선택·귀환 또는 보스전이 자연스럽게 이어지는지
2. 회랑에서 성소가 드러나는 장면과 근접 보스전: 주인공·공격 예고·피할 공간이 잘 보이는지
3. 이동 베기 → 강화 평타의 효과와 대기시간 환급이 이해되고 쓸모 있는지
4. 결과 → 구매 → 별도 장착 → 다음 출정의 변화가 느껴지는지, 종료 후 재실행해 진행이 이어지는지
5. 선택 사항: 야영지 출정의 ‘개발 시험 · 수로도시 장소 경험 (저장·보상 없음)’에서 시장·창고·물가의 연결과 가림을 살펴보기

수로도시 선택 시험
고정 연습 빌드이며 일반 저장·보상·해금은 기록하지 않습니다.
F2 풍경/기존 적 전환 / N 적 초기화 / R 동문으로 복귀 / G 야영지로 복귀

검증 범위
공식 Godot 4.6.3의 동일 버전 엔진/템플릿으로 내보낸 독립 실행 앱입니다.
배포 ZIP의 구조·실행 권한·두 CPU 아키텍처·자체 서명·포함 리소스와 실제 macOS 자동 시작을 검사합니다.
자동 시작은 화면 없이 야영지 로딩과 정상 종료를 확인하는 검사입니다.
사용자 Mac의 실제 그래픽·입력·소리·장시간 성능과 재미·경제 체감은 플레이 확인이 남아 있습니다.
세부 빌드 출처와 실행 파일 해시는 BUILD_INFO.json에 있습니다.
